## Zest-Scripts
zap automation script

This a collection of scripts that can be used in zap to automate some api tests

The following test are covered

-  Input Validation Tests
-  Authorization Tests

-------------

For the Input validation there is a filter (whitelist) for the specific parameters to test otherwie it will test all params which will result in alot of requests.

The test also has to be authenticated so you have to obtain a session token and add it ad a variable.
